# ImaginedNT

A WinUI 3 host for ImaginedNT using the shared **UI-layer window personality** from `ImaginedNT.AppShared`, and able to run some small GDI applications. The same app runs on Windows 10/11 desktop supported by the runtime (x64 for guest execution).

This is the main application we will work at that time, and it is a good starting point for anyone who wants to build a full-trust host for ImaginedNT.
